Google Apps Script 연결

OpenAI API Key와 앱 비밀번호는 GitHub 코드에 넣지 않습니다. 두 값은 Apps Script의 Script Properties에만 저장하고, 이 화면에는 배포 URL과 세션 인증용 비밀번호만 입력합니다.

비밀번호는 브라우저 저장소에 영구 저장하지 않고 현재 탭의 인증 세션을 만드는 데만 사용합니다.
